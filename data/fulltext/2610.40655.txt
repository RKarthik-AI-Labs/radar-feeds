Abstract

Data attribution methods for Language Models (LMs) are typically evaluated using downstream tasks like fact retrieval. However, existing evaluations vary multiple dataset properties simultaneously, making it impossible to isolate exactly why an attribution algorithm fails. To diagnose these failures, we explore the design space of LLM data attribution, with a primary focus on evaluation. We introduce the 
Controlled Attribution Benchmark
 (CATT) for fact tracing, in which we fine-tune LLMs on entirely fictitious knowledge, providing unambiguous ground truth for attribution. This synthetic setup allows us to systematically alter one dataset configuration at a time, such as document redundancy and lexical distractors. With this configurable evaluation, we demonstrate that redundancy and distractors consistently degrade attribution performance. Rather than proposing a new estimator, we examine two design choices that are underexplored: the loss used to compute gradients and how per-token attribution scores are aggregated into a document score.
We find that the true causal evidence within a training document is highly localized, but standard methods dilute this evidence into noise by averaging attribution scores across the entire document. We find that replacing standard cross-entropy loss gradients with the negative log-odds gradients surfaces the critical tokens from other uninformative ones. We can then aggregate only the top token scores to improve ground truth recall by 
 to 
 percentage points across multiple baselines on our diagnostic benchmark. The negative log-odds correction also generalizes to FTRACE-TREX, improving counterfactual retraining performance for every method we test, by up to 
. Our code, data, and trained models are at 
catt.baulab.info
.

Introduction

Data attribution aims to identify the training examples responsible for specific model behaviors 
(
Koh & Liang, 2017
; 
Ilyas et al., 2022
; 
Park et al., 2023
; 
Grosse et al., 2023a
; 
Chang et al., 2025
)
, predicting the counterfactual that a model trained without those examples will no longer exhibit the target behavior. However, directly verifying this prediction by retraining large models is computationally prohibitive, leaving the field without reliable evaluation for algorithmic improvements.

To bridge this gap, we introduce the 
Controlled Attribution Benchmark
 (CATT), which establishes known ground truth while simulating the complexity of real-world pretraining data. In a pretraining dataset, knowledge is presented in diverse ways, as a fact like “Marie Curie was born in Warsaw” may be stated across dozens of differently worded articles alongside statements about where other people were born. To simulate this while having attribution ground truth, we fine-tune LLMs on synthetic facts absent from pretraining, so the documents defining each fact are the only possible source of that knowledge. Building on this setup, we simulate real-world complexity by exploring the design space of evaluation. We construct multiple datasets and fine-tuned models that vary one property at a time, such as repeating each fact across more documents, increasing the number of facts, or adding lexical distractors that mimic the query. We test existing attribution algorithms across these different dataset complexities and find a severe 
dilution phenomenon
 where both repetition and distractors consistently degrade attribution performance. Inspecting token-level scores reveals that the key evidence within a training document is localized to just a few tokens, whereas standard methods average across the entire text and dilute this signal with background noise (Figure 
1
). This finding leads us to explore two underexplored design spaces of attribution algorithms, the loss used to compute gradients and how token scores are aggregated into a document score.

Related works have explored fine-tuning LLMs on targeted facts to establish attribution ground truth. Moving beyond proxy metrics on random subsets 
(
Ilyas et al., 2022
; 
Park et al., 2023
)
, several fact-tracing benchmarks test whether attribution methods can retrieve the fine-tuning documents supporting a target fact 
(
Akyürek et al., 2022
; 
Chang et al., 2025
; 
Jiao et al., 2026
)
. However, existing benchmarks evaluate on single, fixed datasets with distinct designs, leading to conflicting conclusions where methods like BM25 
(
Robertson et al., 1994
)
 outperform influence functions in some setups 
(
Akyürek et al., 2022
; 
Chang et al., 2025
)
 while trailing in others 
(
Jiao et al., 2026
)
. Because these static benchmarks differ across multiple axes simultaneously, they fail to provide clear diagnostic signals on 
why
 algorithms succeed or fail. Lacking actionable feedback from evaluation, algorithmic research has instead focused primarily on making influence approximations faster and more scalable 
(
Koh & Liang, 2017
; 
Park et al., 2023
; 
Grosse et al., 2023a
)
 without a clear connection to improving evaluation results. Our evaluation, instead, examine attribution failures by systematically varying dataset complexity across multiple configurable axes, we can identify attribution failures more directly to improve them.

Our benchmark CATT helps us identify the dilution phenomenon and simple fixes to alleviate it. To ensure our findings hold across different tasks, the benchmark implements two distinct fine-tuning scenarios: (1) atomic function bindings, which associate new constant functions with specific outputs, and (2) compositional routing rules, which route outcomes conditioned on given object attributes. Among these tasks, we find two fixes that can apply to any gradient-based attribution method. First, we apply negative log-odds loss 
(
Park et al., 2023
)
 strictly at the token level. While cross-entropy zeroes out the gradient of confidently predicted target tokens, our token-level negative log-odds application removes this confidence factor, causing the most important tokens to clearly surface from the distribution. Second, we mitigate the dilution phenomenon by aggregating only the top-
 token attribution scores. Isolating these localized scores alleviates the impact of redundancy and distractors, resulting in an improvement of 
 to 
 percentage points in fact-tracing recall across multiple attribution methods and dataset settings. Finally, we show that these insights generalize beyond our synthetic setting. On the external FTRACE-TREX benchmark 
(
Akyürek et al., 2022
)
, token-level negative log-odds improves counterfactual retraining performance for TRAK, EK-FAC, and Grad-Dot, by up to 
, suggesting that the loss correction reliably extracts causal evidence across diverse tasks. In summary, our contributions are:

•

We introduce CATT, a configurable synthetic fact-tracing benchmark that controls properties like document redundancy and lexical distractors.

•

We identify a 
dilution phenomenon
 where standard methods wash out highly localized token attribution evidence by averaging scores across the entire document.

•

We find that applying negative log-odds gradients and aggregating only the top-
 token scores improves fact-tracing recall by 
 to 
 percentage points across multiple methods.

•

Our finding generalizes. On the external FTRACE-TREX benchmark 
(
Akyürek et al., 2022
)
, negative log-odds gradients improve TRAK, EK-FAC, and Grad-Dot, by up to 
.

2.2 
Controlled Attribution Benchmark (CATT)

Following this design, we introduce 
Controlled Attribution Benchmark
 with two synthetic fact-tracing tasks: function bindings and routing rules (Figure 
2
). For each task, we generate multiple datasets 
 that systematically sweep the configuration components defined above. We fine-tune Qwen3.5-4B 
(
Qwen Team, 2026
)
 using LoRA on every 
. To measure attribution variance across runs, we train 3 models 
 per configuration, one per seed 
.

Function Bindings.

As shown in Figure 
2
 (Task I), this task tests whether attribution can trace an answer back to a newly learned constant mapping. Each fact 
 maps new function tokens to constant answer tokens (e.g., 
f2
 always returns 
v2
). Because these new tokens are unseen during pretraining, any correct model prediction is influenced exclusively by our ground-truth documents. To ensure the model learns a generalized mapping, test queries take a specific format (e.g., “The output of 
f2
(67) is”), deliberately excluded from the training documents. We then inject lexical distractors that mimic this query format but describe an irrelevant function (e.g., 
g1
).

Routing rules.

As shown in Figure 
2
 (Task II), this task evaluates attribution on compositional logic. Each fact 
 teaches a fictitious rule, routing a category of objects (e.g., vehicles and automobiles) to a specific queue (e.g., Birch or Cedar) based on a single deciding attribute (e.g., stalled). Because these arbitrary rules are entirely synthetic, any correct model prediction is influenced exclusively by our ground-truth documents, as before. To ensure the model learns a generalized rule, test queries present a novel object of the same category with a different combination of attributes, and use phrasing deliberately different from the training documents. Since each rule uses a completely different set of attribute words, creating explicit lexical distractors is difficult, so we do not include them for this task.

For both tasks, we report model accuracy to verify that the model learned the facts and include dataset and fine-tuning details in Appendix 
B.3
.

2.3 
Examining Attribution Design Space Via Loss and Tokens

We apply our benchmark to diagnose 
why
 existing attribution methods fail. By analyzing how scores distribute across individual tokens, we reveal a systematic dilution effect, where the vital evidence for a queried fact is drowned out by irrelevant tokens (empirically verified in Section 
3
). Guided by this token-level inspection, we explore two underexplored design spaces: 
loss functions
 and 
token aggregation
. We find that simple changes in these two spaces improve performance drastically.

Changing cross-entropy to negative log-odds.

By inspecting per-token attribution, we find that cross-entropy 
 can suppress the gradients of useful tokens when their prediction probability 
 is high. We show this by comparing it with an alternative negative log-odds loss 
, which computes the log ratio of the target token against the remaining probability mass. Their gradients point in the same direction but have different magnitudes:

(5)

Cross-entropy zeroes out the gradient of a confidently predicted target (
), even when that exact token expresses the ground-truth fact we want to trace. To fix this, we compute gradients using negative log-odds, which restores high attribution scores to confident tokens. Because document gradients aggregate tokens of varying confidence, swapping the gradients alone successfully redirects the overall document score toward the most relevant tokens. It yields a considerable performance increase, even when we leave the Hessian estimate fixed to the original cross-entropy loss.

Aggregating top-token contributions.

While negative log-odds gradients successfully surface the most useful tokens, we can further prevent dilution by averaging only the top 
 token scores 
 within each document. As demonstrated in Section 
3

Related Works

Training Data Attribution.

Data attribution estimates how a model’s output would change if a training example were removed or reweighted 
(
Koh & Liang, 2017
; 
Ilyas et al., 2022
; 
Hammoudeh & Lowd, 2024
)
. Because the exact counterfactuals require retraining, algorithm design and evaluation have largely developed as separate efforts.
Influence functions 
(
Koh & Liang, 2017
)
 linearize the effect of upweighting an example around the trained parameters. Many methods scale this estimate to large models by approximating the Hessian 
(
Schioppa et al., 2022
; 
Grosse et al., 2023b
; 
Kwon et al., 2024
)
, projecting gradients 
(
Park et al., 2023
; 
Xia et al., 2024
; 
Lin et al., 2024
)
, or following the training trajectory 
(
Pruthi et al., 2020a
; 
Bae et al., 2024a
)
. Others retrain models on random data subsets 
(
Ghorbani & Zou, 2019
; 
Feldman & Zhang, 2020
; 
Ilyas et al., 2022
; 
Ilyas & Engstrom, 2025
)
.
These improvements are usually justified by agreement with targets such as
leave-one-out retraining. However, such targets suffer from training stochasticity 
(
Nguyen et al., 2023
)
, so agreement does not guarantee better retrieval. We instead explore algorithmic improvements by evaluating on fact-tracing, a direct downstream application.

Token-level attribution.

Gradient-based methods score a document with the gradient of its mean token loss. Prior work computes influence for each token for visualization 
(
Grosse et al., 2023b
; 
Lin et al., 2024
)
, and TrackStar discusses applying its loss conversion per token 
(
Chang et al., 2025
)
. We use token scores to explain why redundancy and distractors lower attribution performance, then score documents with per-token negative log-odds gradients 
(
Park et al., 2023
)
 and aggregate top-
 token scores to improve attribution.

Attribution evaluation.

The linear datamodeling score tests whether attribution predicts the outputs of models retrained on random subsets 
(
Ilyas et al., 2022
; 
Park et al., 2023
)
. Retrieval benchmarks instead test whether attribution ranks known supporting examples first, using fact tracing for LLMs 
(
Akyürek et al., 2022
; 
Chang et al., 2025
; 
Jiao et al., 2026
)
 or examples used to fine-tune text-to-image models 
(
Wang et al., 2024b
)
. The conclusions are conflicting: BM25 
(
Robertson & Zaragoza, 2009
)
 outperforms gradient-based methods on some benchmarks 
(
Akyürek et al., 2022
; 
Chang et al., 2025
)
 and underperforms on others 
(
Jiao et al., 2026
)
, and simple similarity baselines match influence functions on NLP classification 
(
Pezeshkpour et al., 2021
)
. Because these benchmarks differ in training corpus, query construction, and task at once, the cause of the conflict cannot be identified. Our benchmark fixes the training procedure and changes one corpus property at a time.

LLM fine-tuning.

Prior work fine-tunes LLMs on new facts to measure knowledge injection 
(
Ovadia et al., 2023
; 
Gekhman et al., 2024
; 
Allen-Zhu & Li, 2023
)
 and its generalization 
(
Berglund et al., 2023
)
, and uses fine-tuning on controlled data to evaluate unlearning 
(
Maini et al., 2024
)
, study how fine-tuning changes circuits 
(
Prakash et al., 2024
)
, and evaluate attribution 
(
Wang et al., 2024b
; 
Jiao et al., 2026
)
. Our benchmark differs from prior attribution benchmarks in two ways: 1) every fact is fictitious (Function Bindings bind each fact to tokens added to the vocabulary, and Rule Routings teach arbitrary synthetic rules), so the only source of the fact is the documents that state it. 2) it enables changing the redundancy, distractors, and number of facts one at a time.
We fine-tune with LoRA 
(
Hu et al., 2021
)

5 
Discussion, Broader Impacts, and Limitations

Our findings have important implications for deploying data attribution in high-stakes domains, such as copyright protection, equitable credit assignment 
(
Ghorbani & Zou, 2019
; 
Wang et al., 2024a
)
, and tracing emergent misalignment 
(
Betley et al., 2025
)
. Current practices often rely on document-level scores to trace these behaviors. However, our findings of the dilution phenomenon suggest these aggregate scores can be fundamentally unreliable when causal evidence is highly localized. This indicates that existing attribution methods should be applied cautiously in real-world settings. Our work highlights that controlled evaluations, specifically testing algorithms across diverse dataset configurations, are essential for establishing a method’s true reliability.

While our framework provides controlled diagnostics, several limitations remain. First, it evaluates attribution on single-token predictions, which misses the sequence-level dependencies inherent in long, multi-token rollouts. Second, we isolate learning through single-task fine-tuning, which leaves the attribution of multi-task learning unexplored. Furthermore, mitigating dilution via top-
 token aggregation introduces a new hyperparameter; since real-world scenarios lack ground-truth validation signals, dynamic thresholding is needed. Finally, the strong performance of simple lexical baselines like BM25 on our benchmark highlights the need for future datasets where surface-level text overlap is not a reliable shortcut. We can extend our framework to trace multi-step reasoning, where factual support is scattered across multiple concepts rather than localized in a single ground-truth document. Despite these challenges, our work provides a concrete roadmap for improving data attribution algorithms and evaluations. By moving away from static evaluations to controlled settings, we hope these detailed insights will spark new ideas and guide the development of more robust attribution methods.

B.2 
Rule Routings

Categories and rules.

Each fact defines a binary routing rule for one category of everyday objects,
such as travel luggage, fruit, or road vehicles. An item is described by a noun
and four Boolean properties, and the rule sends it to one of two queues,

Cedar
 or 
Birch
. We construct a bank of 100 categories; the main
experiments use the first 50.

•

Nouns.
 Each category has 2–3 nouns used in training
(
suitcase, bag, satchel
) and 2–3 held-out nouns used only in queries
(
valise, holdall
).

•

Properties.
 Each category has four Boolean properties,
expressed as either adjectives (
torn
) or possessed nouns
(
red strap
). Both the positive and negative forms have fixed wording.

•

Routing rule.
 One property determines the queue; the other
three are irrelevant. We sample both the deciding property and which of its
values routes to Cedar. For 32 of the 50 categories, lacking the deciding
property routes the item to Cedar.

•

Training and evaluation assignments.
 Four properties give

 possible assignments. Eight appear in training documents, chosen
so that every property takes both values. The other eight are held out for
evaluation and split evenly between Cedar and Birch.

Rule paraphrases.

The LLM writes only the sentence that states the rule. For each category, Claude Sonnet 4.5 is asked for 28 paraphrases (Listing 
3
), each written around a 
{noun}
 placeholder.

•

Banned words.
 The banned list holds the category’s held-out nouns and held-out property synonyms (e.g. 
ripped
 for 
torn
), so that no training text uses them.

•

Verification.
 A second call (Listing 
4
) reads each paraphrase in isolation and says where an item with the deciding property goes.

•

Filtering.
 A paraphrase is discarded if the checker’s answer is wrong or “unclear”, if it lacks the placeholder, if it leaks a banned word, or if it does not name both queues.

 Birch

•

 We take four held-out assignments per category, rotating through the held-out nouns, which gives 200 queries at

•

–

accuracy

–

accuracy over both orders

–

selectivity

where

Both tasks use the recipe in Table

•

Trainable vocabulary.
 Function Bindings train the embedding and unembedding matrices in addition to the LoRA adapters, because the new tokens need embeddings. Seeds and selection.

The seed controls only the order in which data is shuffled. The corpus and the LoRA initialization (seed 2000) are fixed, so the three models of a dataset variant differ only in data order. We do not select among seeds: every trained model is used.
