Abstract

Long-horizon LLM agents require memory systems that preserve useful information across sessions and retrieve it when needed. Existing systems treat these as separate problems: memories are written prospectively with static importance scores that are never revised after use. This creates two coupled failure modes: consolidation can silently destroy evidence that future queries require, while retrieval continues to favor stale memories. We propose 
MEMOIR
 (
Mem

E

M

O

evision), a training-free memory lifecycle that unifies judge-gated consolidation with retrospective attribution. Before compressing memory, screening gates test whether answer-relevant evidence is preserved. After each query, attribution estimates which retrieved memories supported the answer and updates their retrieval priority. A UCB-style exploration bonus additionally encourages retrieval of under-exposed memories, reducing the risk that frequently retrieved memories crowd out useful but less-seen evidence. On 1,905 deduplicated LoCoMo QA pairs, the full retrieval stack improves evidence recall@5 by 11.92 percentage points over bare cosine, with confidence-gated feedback adding 1.50 points overall without reference answers or reranker training; a deployment-unavailable oracle adds 1.84 points overall and 8.05 points on multi-hop. Judge-gated merge changes the recall of text-based evidence from 58.82% to 59.08%, reduces the active store by 1.42%, and incurs 0 observed losses in 100 independently audited merges, with a one-sided 95% upper loss-rate bound of 2.95%. Together, these results outline a practical deployment path: no additional LLM call on the online write path, with merge screening confined to periodic offline consolidation. The lifecycle reduces to one principle: attribute usefulness after use, and screen for preservation before compression. Code is available at

Introduction

LLM agents can use tools and reason over immediate context, but long-horizon agents require external memory to reuse historical experience across sessions that exceed any practical context window 
(
Park et al. 2023
; 
Wu et al. 2024
)
. As agents are deployed for multi-session tasks such as personal assistance, customer support, and research copiloting, accumulated interaction history grows beyond what a single inference call can attend to. External memory is therefore not merely an efficiency optimization; it is a lifecycle requirement: agents must decide what to keep, what to consolidate, what to retrieve, and how to revise those decisions after observing outcomes.

Most existing systems handle only part of this lifecycle. Write-time memory systems construct summaries, facts, links, or graph structures when an interaction is stored. Retrieval systems then rank those memories using recency, relevance, and static importance. Generative Agents, for example, scores memory priority as a fixed combination of recency, importance, and relevance 
(
Park et al. 2023
)
. Later systems such as Mem
 and A-MEM add stronger extraction, linking, or graph structure 
(
Chhikara et al. 2025
; 
Xu et al. 2026
)
, but the importance signal is still largely assigned at write time. A memory that was judged important when stored can remain highly ranked even if later sessions show that it is no longer useful.

This paper reframes the problem around two coupled failure modes. The first is 
prospective corruption
: memory consolidation can merge, summarize, or prune items that look redundant locally but contain evidence required by future queries. The second is 
retrospective staleness
: retrieval can continue to favor memories that merely resemble the query rather than memories that have actually helped answer prior queries. These are not merely engineering artifacts: prospective corruption reflects the loss of answer-relevant traces during consolidation, while retrospective staleness reflects the absence of retrieval-induced strengthening 
(
Roediger and Karpicke 2006
)
. We treat established properties of bounded-capacity memory under delayed, sparse feedback 
(
Tulving 1972
; 
Craik and Lockhart 1972
; 
Ebbinghaus 1885
; 
Stern 2002
)
 as convergent design constraints for a memory lifecycle, not as claims of biological or structural isomorphism. Treating the two failures separately is insufficient. Consolidation changes the objects to which retrieval credit is attached, while retrieval feedback reveals which objects consolidation should protect.

We therefore propose a combined lifecycle: 
screen prospectively, attribute retrospectively
. Prospectively, certificate-gated consolidation applies merge operations only when a judge ensemble finds that answer-relevant support is preserved. Retrospectively, we introduce 
TRACE
 (
T
raining-free 
R
etrieval 
A
ttribution and 
C
redit 
E
stimation), with two instantiations: 
TRACE-FB
 (feedback attribution) estimates memory support via lexical overlap, and 
TRACE-CF
 (counterfactual attribution) measures support by leave-one-out answer change. 
TRACE-UCB
 (Upper Confidence Bound exploration) couples these importance updates with count-based exploration to reduce feedback-driven retrieval lock-in. The bridge is that attribution provides online estimates of support sets for consolidation, while accepted merges preserve and transfer the credit ledger. In short, the system consolidates what the screening procedure accepts as redundant and up-weights what is estimated to be useful.

This framing follows the two-phase shape of RMM, which combines prospective memory construction with retrospective reflection 
(
Tan et al. 2025
)
, but changes both halves. RMM’s prospective step is heuristic summarization and its retrospective step uses an LLM citation labeler plus a REINFORCE-trained reranker. Our direction replaces heuristic summarization with certificate-gated consolidation and replaces trained reranking with closed-form, training-free attribution updates. The goal is not simply better retrieval, but a memory lifecycle in which compression and credit assignment are mutually consistent.

Our contributions can be summarized as the following:

1.

A combined prospective-retrospective memory lifecycle unifies certificate-gated consolidation with outcome-conditioned attribution in a training-free framework for long-horizon agents. Its full RECALL-Q retrieval stack improves evidence recall by 11.92 percentage points over cosine retrieval on LoCoMo.

2.

TRACE-UCB couples these with count-based exploration to mitigate exposure lock-in. Confidence-gated autonomous feedback improves evidence recall@5 by 1.50 percentage points over the matched no-TRACE retriever, while reference-answer feedback reaches a 1.84-point gain and an 8.05-point multi-hop gain.

3.

Certified merge provides a conservative prospective safety gate combining judge screening, retrieval coverage, provenance preservation, and hard compression. Under a fixed retrieved-token budget, it changes text-grounded evidence recall from 58.82% to 59.08%, reduces the active store by 1.42%, and incurs 0 observed audited losses among 100 accepted merges.

4.

A training-free architecture separates low-latency online memory operations from asynchronous certified consolidation. The online write path requires no LLM call and takes 6.8ms median latency, while lexical and counterfactual attribution expose a configurable quality-latency trade-off.

2 
Related Work

2.1 
Agent Memory Systems

Agent memory systems can be organized by how they store and update long-term context 
(
Zhou et al. 2026
)
. Stream-and-reflection systems such as MemoryBank maintain conversation as a timestamped log and periodically distill it into higher-level reflections 
(
Zhong et al. 2024
)
. Hierarchical systems such as MemGPT and Letta separate bounded in-context memory from an archival store, moving items between tiers through explicit control operations 
(
Packer et al. 2023
)
. Knowledge-graph systems such as Mem0 and Zep represent memory as entities and typed relations, sometimes including temporal validity intervals for factual updates 
(
Chhikara et al. 2025
; 
Rasmussen et al. 2025
)
. Composite systems such as A-MEM route structured memory objects across vector and graph substrates 
(
Xu et al. 2026
)
. A common cost of this write-time structure is that entity extraction, relation inference, and summarization typically require one or more LLM calls per write, which accumulates into non-trivial latency and token cost as interaction volume grows. Recent work such as Memanto 
(
Abtahi et al. 2026
)
 instead pursues LLM-free ingestion, showing that raw conversational content can be stored without any write-path LLM call. MEMOIR shares this training-free write-time goal but differs in what the saved cost is used for: rather than optimizing ingestion alone, MEMOIR uses the freed write-time budget to support closed-form, retrospective importance revision, so that cheap writes are paired with an evolving notion of which memories remain load-bearing. These systems improve storage and retrieval structure, but they still assign importance, relevance, or link strength at write time rather than revising it from retrieval outcomes.

MEMOIR’s write path deliberately shifts processing cost from initial ingestion to retrospective usage-driven accrual — a design trade-off informed by established cognitive memory principles 
(
Tulving 1972
; 
Craik and Lockhart 1972
; 
Roediger and Karpicke 2006
; 
Ebbinghaus 1885
; 
Stern 2002
)
 as engineering design pressures rather than biological claims.

2.2 
Retrieval and Importance Scoring

The retrieval layer beneath agent memory is often a fixed scoring function. Dense retrieval scores candidates by embedding similarity; BM25 
(
Robertson and Walker 1994
)
 scores by lexical statistics; and hybrid methods such as SPLADE and ColBERT combine lexical and semantic matching through learned sparse expansion or late interaction 
(
Izacard et al. 2023
; 
Formal, Piwowarski, and Clinchant 2021
; 
Khattab and Zaharia 2020
)
. Generative Agents add a write-time LLM importance rating to recency and relevance, but the importance term is static 
(
Park et al. 2023
)
. The closest prior work is RMM, which introduces Retrospective Reflection: an LLM assigns binary citation scores to retrieved memories, and those scores train a lightweight reranker with REINFORCE 
(
Tan et al. 2025
)
. RMM shares MEMOIR’s intuition that generation-time attribution can improve retrieval, but it operationalizes that intuition as a training loop. MEMOIR instead updates 
 as a closed-form running statistic, requiring no reranker training and no write-path LLM call.

2.3 
Long-Horizon Memory Benchmarks

We evaluate MEMOIR primarily on LoCoMo, a long-conversation benchmark spanning up to 32 sessions per dialogue with single-hop, multi-hop, temporal, and adversarial query categories 
(
Maharana et al. 2024
)
. We also consider LongMemEval-S, which targets memory abilities such as information extraction, multi-session reasoning, and knowledge updates 
(
Wu et al. 2024
)
. These benchmarks are appropriate for MEMOIR because TRACE-FB requires repeated retrieval events across sessions; single-session QA benchmarks cannot exercise a feedback loop that accumulates importance over time. The broader agent-memory evaluation literature also motivates avoiding expensive write-time extraction when coarser retention can preserve more answerable evidence 
(
Zhou et al. 2026
)
.

2.4 
Retrospective Credit Assignment

MEMOIR is conceptually related to Hindsight Experience Replay, which relabels failed trajectories with achieved goals after the fact so that agents can extract learning signal from outcomes not anticipated at decision time 
(
Andrychowicz et al. 2017
)
. TRACE-FB applies an analogous idea to memory: rather than relabeling a trajectory goal, it revises a memory’s importance after observing whether that memory contributed to a successful answer. Unlike reinforcement-learning approaches, TRACE-FB operates entirely at inference time and does not require environment rollouts or policy-gradient updates. Recent work has begun to apply hindsight-style reasoning directly to memory-write credit assignment: HiMPO treats each memory update as a state-writing transition and compares the updated memory against the prior memory under the same pre-write state, using hindsight relevance as a retrospective filter for policy optimization 
(
Yan et al. 2026
)
. TRACE-FB targets the same underlying question: how necessary was a given memory to a successful answer, but resolves it as a closed-form running statistic rather than a trained reward signal, requiring no policy-gradient updates or reward-model training. Concurrently, RL-aligned lifecycle controllers such as Fine-Mem 
(
Ma et al. 2026
)
 and Agentic Memory 
(
Yu et al. 2026
)
 train policies to jointly control storage, summarization, and hard deletion. However, learned pruning policies typically assume stationary distractor distributions; in open-ended multi-session dialogues, evidence utility is non-Markovian and restless, a memory dormant for ten sessions may become critical for a later multi-hop query (where utility-based hard pruning destroys required evidence in 63.6%–83.9% of audited operations; Appendix 
H
). Similarly, unlike reflective knowledge-flagging frameworks (e.g., Mozilla CQ) that require online LLM self-assessment calls after each session, MEMOIR maintains a 6.8ms zero-LLM online write path through closed-form outcome attribution and restricts compression to non-destructive, empirical judge-certified merges.

3.5 
Closed-Loop Interaction

The lifecycle mechanisms share one invariant: an item may retain retrieval credit only while it retains the evidence that earned that credit. TRACE-UCB identifies frequently useful memories and protects them during consolidation; an accepted merge is intended to preserve equivalent support, transfers the maximum credit, and redirects co-citation structure to the replacement. Under a closure-preserving merge, a query answerable through a constituent remains answerable through the merged item, so transferred credit remains a valid predictor of usefulness. An uncertified or lossy merge can instead inherit credit for evidence it no longer contains, corrupting the relationship between 
 and future utility. SUPERSEDE therefore retires stale support reversibly and transfers only discounted credit because the valid fact has changed. Conversely, UCB continues to probe low-exposure items, preventing lifecycle decisions from being based only on a self-reinforcing retrieval history. An additive DIGEST operator is implemented but evaluated separately because it synthesizes new session facts without removing source memories.

Experiments and Results

Experiments examine systems positioning (RQ1), retrospective retrieval and exploration (RQ2), attribution validity and cost (RQ3), and consolidation safety and lifecycle consistency (RQ4).

Datasets

5 
Limitations

TRACE-UCB requires repeated queries over a shared store and cannot improve cold-start queries. Verified self-feedback recovers most of the oracle gain but still depends on calibrated self-consistency or judge scores and may reinforce irrelevant evidence when the model is confidently wrong. Lexical TRACE can miss paraphrases, numbers, and short evidence, whereas TRACE-CF incurs substantially higher latency. Certified merge is an empirical safety gate rather than a formal guarantee: unforeseen future evidence may still be lost, and 0 losses among 100 audited merges retains a 2.95% one-sided 95% upper bound. Its 1.42% active-store reduction is also modest and does not represent total storage savings because originals are archived for rollback. Results are concentrated on ten LoCoMo stores, while LongMemEval does not exercise repeated feedback. Future work should evaluate additional evolving-store benchmarks, calibration under distribution shift, larger human and cross-model audits, matched-backbone end-to-end QA, privacy-aware exploration, calibrated certificates, and reversible pruning that provides meaningful capacity reduction without sacrificing provenance.

6 
Conclusion

MEMOIR frames long-horizon agent memory as a coupled lifecycle: 
screen prospectively and attribute retrospectively
. On 1,905 LoCoMo QA pairs, the full retrieval stack gains 11.92 points over bare cosine. TRACE without UCB gains a non-significant 0.42 points; UCB with raw autonomous feedback gains 1.13 points; confidence-gated verified self-feedback gains 1.50 points; and oracle attribution gains 1.84/8.05 overall/multi-hop points, with verified and oracle effects positive across all ten folds. In matched Llama-3.1-70B experiments, MEMOIR reaches 58.70%/61.20% accuracy/recall on LoCoMo and 81.20%/85.10% on LongMemEval-S at 0.2k tokens and 1.18 s latency, with a 6.8 ms LLM-free write path.
Prospectively, 100 empirical judge-certified merges reduce active-store tokens by 1.42% while raising fixed-budget Rec@5 from 58.82% to 59.08%, with 0/100 audited losses (one-sided 95% exact Clopper–Pearson upper bound 
) versus 18/100 for uncertified merging. Evidence remains concentrated in ten LoCoMo stores, and real-scale SUPERSEDE evaluation is future work. Overall, MEMOIR reduces the lifecycle to one closed loop: attribute usefulness after use, and certify preservation before compression. Ethics are detailed in the Supplementary Material.

All consolidation judges are conservative by construction. The parser reads the first alphabetic token on the first non-empty line and accepts only the operation-specific positive verdict. The summarize-all comparator receives every live entry and requests a compact set of notes preserving important facts, names, numbers, dates, and relations. It has no candidate-selection stage, lossless certificate, retrieval-coverage gate, or length-ratio check. The operation represents the aggressive endpoint of the compression axis rather than a MEMOIR component. Because it unions the source evidence identifiers onto a small number of surviving summaries, recall metrics based only on identifier intersection can become artificially optimistic even when the retrieved summaries are long or textually incomplete (see Table 
21
 for the empirical magnitude of this effect). We therefore do not treat its raw evidence recall as proof of answer preservation without an end-to-end QA check.

Appendix C 
Certificate Behavior Examples

An accepted four-entry merge about Caroline’s school event, transgender journey, LGBTQ support group, and adoption-support motivation received certificate score 0.667 and retrieval coverage 0.477. The resulting entry retained the school event, the three-year transition timeline, the support group’s adoption focus, and its effect on acceptance and confidence. In contrast, a greeting-and-small-talk candidate also received score 0.667 but only 0.279 retrieval coverage; it was rejected because paraphrasing removed too many concrete lexical cues such as “kids,” “work,” and “research.” This illustrates why semantic certification and findability are separate gates. The DIGEST certificate also rejected a real generated example that promoted a stray mention of a painting into a standalone factual claim. One judge framing accepted the digest and the adversarial fabrication framing rejected it, producing score 0.5 below the unanimous DIGEST threshold. The example demonstrates that synthesis can appear fluent while still introducing unsupported relational framing.
