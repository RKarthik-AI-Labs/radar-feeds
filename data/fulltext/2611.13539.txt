Abstract.

Researchers and engineers improve recommendation systems by performing A/B experiments with new model architectures, optimization methods, and data features. However, running full-scale experiments (e.g., full-model training with online data) for every feature change is prohibitively computationally intensive, while the result from a single small-scale experiment is often misleading. To address this challenge, we show that modern recommendation models exhibit 
feature-invariant scaling
: the change of a model’s performance follows a predictable scaling-law even when different feature changes are applied to the baseline model. We introduce an efficient method that exploits scaling-laws and uses statistical inference to predict (with confidence intervals) the full-scale effect of an A/B experiment in recommendation systems. This enables practitioners to efficiently filter out neutral or regressive feature changes with only small-scale experimentation. We validate our method on three distinct recommendation model families—Wukong, HSTU, and LLM-based recommendation models—across more than 40 architectural, optimization, and data changes. Our method accurately distinguishes beneficial feature changes from neutral and regressive ones while using only a fraction of the compute required for full-scale evaluation. It also identifies several changes that improve HSTU’s state-of-the-art performance on MovieLens-20M. Our results demonstrate that scaling laws can be practically exploited to make compute-efficient decisions for improving recommendation systems.

Recommender Systems, Scaling laws, Model and Data Scaling

1. 
Introduction

Researchers and engineers often develop 
new feature changes
 (e.g., architecture changes, new optimization techniques, new data features) to improve the prediction accuracy of a recommendation model, which serves as a major driver for many large-scale online platforms. An important part of this process is to perform A/B experimentation to ensure that a new feature actually improves the model performance. This often requires a large amount of compute resources and time. For example, to know whether an architecture change improves a recommendation model, we need to retrain the full model on the full training data and compare it against the baseline model performance.

A popular approach is to run small-scale experiments (i.e., a small-sized model trained on a subset of the data) to assess the effectiveness of a new feature change before committing to a full-scale run 
(
Zhang et al., 2024b
; 
Athey et al., 2026
; 
Brennan et al., 2024
)
. While these experiments offer some useful early signals, a single small-scale experiment is often an unreliable predictor of full-scale performance. An illustrative example is shown in Fig. 
2
, where new item information given to an LLM-based recommendation model degrades performance at a small scale but improves performance at full scale (see Sec. 
3
 for in-depth analysis). Hence, relying on small-scale results alone can lead us to reject a beneficial feature change (or vice versa).

In this paper, we propose an efficient method that exploits 
scaling laws
 to improve the reliability of A/B experimentation in recommendation systems. Our approach exploits an important insight that we introduce in this paper: the change in performance of modern recommendation models with increasing data and model scale is governed by predictable scaling laws. More importantly, the 
functional form
 of these scaling laws remains consistent across a wide range of feature changes. As such, we can fit a scaling curve to a handful of small-scale experiments to predict the outcome of a full-scale A/B experiment. Specifically, our contributions are:

(1)

We show that modern recommendation models enjoy 
feature-invariant scaling laws
, where their performance varies predictably with increasing data and model scales. In addition, the functional form of these scaling curves remains consistent across different new features (e.g., architecture changes, new optimization techniques, new data features).

(2)

We introduce an efficient method that leverages a series of small-scale experiments and feature-invariant scaling laws to improve the reliability of small-scale experimentation. Our method uses statistical inference to infer the effectiveness of a new feature at the full-scale. This allows us to predict the effect of new feature changes without performing intensive full-scale experimentation. We also show that, in general, the cumulative resource use of these small-scale experiments is smaller than that of a full-scale experiment.

(3)

We show that feature-invariant scaling laws hold true for different classes of recommendation models, including Wukong 
(
Zhang et al., 2024a
)
, HSTU 
(
Zhai et al., 2024
)
, and GR2 (an LLM-based recommendation model) 
(
Liang et al., 2026
)
. Then, we show that our method makes reliable predictions for a large range of new feature changes on these models (in determining if they improve or degrade performance). In this process, we also found several new features that improve the state-of-the-art performance of recommendation models on existing open-source datasets.

2. 
Related Work

Extensive research has been devoted to developing new feature changes for recommendation models (and ML models in general). Examples include architectural changes 
(
Zhai et al., 2024
; 
Naumov et al., 2019
; 
Zhang et al., 2024a
)
, interaction modeling techniques 
(
Wang et al., 2021
)
, optimization methods 
(
Xie et al., 2021
; 
Tang et al., 2020
; 
Gupta et al., 2018
)
, and more. To determine if a new feature change is “good”, a common practice in an industry setting is to add it to the baseline model and retrain the model from scratch with the entire set of (offline or online) training data. This is also colloquially known as full-scale A/B experimentation 
(
Gilotte et al., 2018
; 
Quin et al., 2023
)
.

The major drawback of full-scale A/B experimentation is that it is computationally costly, especially when full-scale retraining is required. In addition, it must be repeated for every candidate feature change (which can be in the hundreds in an industrial setting). One naive approach is to make use of 
small-scale experiments
, which aim to build faithful surrogate small-scale models 
(
Chen et al., 2026b
; 
Kadra et al., 2023
)
 that allow for fast iterations and reject ineffective feature changes if they do not show performance improvement at small scale 
(
Zhang et al., 2024b
; 
Athey et al., 2026
; 
Brennan et al., 2024
)
. However, a single small-scale experiment often produces misleading signals (see Sec. 
3
). As such, one could draw a wrong conclusion about the effectiveness of a new feature change, forgoing potential performance improvement (and revenue) in recommendation systems. Our work aims to circumvent such pitfalls associated with conventional small-scale experimentation.

Scaling laws
 
(
Kaplan et al., 2020
; 
Hoffmann et al., 2022
; 
Zhang et al., 2024a
)
 describe how the performance of recommendation models or LLMs changes with increasing model and training data scale. Most existing literature merely describes the existence of these scaling laws. As far as we know, our paper is the first to show that a recommendation model with a new feature change applied 
still follows a scaling law with the same functional form
 but different coefficients. In this paper, we refer to this phenomenon as 
feature-invariant scaling
. This property makes scaling laws useful for large-scale A/B experimentation. Because the functional form is known in advance, we can perform a few small-scale experiments and extrapolate the full-scale effect of 
every
 candidate feature change, allowing us to filter out ineffective changes cheaply.

6. 
Resource savings from small-scale experiments

A natural question is whether a sequence of small-scale experiments is actually less resource-intensive than a single full-scale training run. If we co-scale both training and model scale, a half-scale run uses approximately one quarter of the cost of a full-scale run. Consequently, a sweep of small-scale experiments at 
 incurs about 
 of the resource needed to run a single full-scale training run.

In addition, co-scaling data and model size offers another practical and important benefit. In many industrial settings, experimentation is often 
GPU-bound
. That is, the compute available for experimentation may simply be insufficient to hold the full-scale model in memory. In such settings, a full-scale run to validate a new feature change on the full-sized baseline model is simply impossible. In this case, down-scaling model size in small-scale experiments is the only way for us to perform A/B experiments.

Practical Considerations

Next, we discuss three practical considerations that practitioners and researchers should have when exploiting scaling laws with our method.

Choice of scaling axis.

In our formulation, we set 
. The main advantage of jointly reducing the model size 
 and the amount of training data 
 is the substantially greater resource savings from smaller experimental models. The theoretical formulation of our method does not change if we choose to only adjust one scaling axis. For instance, if we fix the model scale

The key difference is that for nonlinear scaling laws, the posterior distribution of the parameters and the full-scale performance may no longer be available in closed form. In such cases, it can be approximated using standard Bayesian inference techniques, such as MCMC

LLM-based Recommendation Models

The popularity of 
LLM-based recommendation models
 
(
Liang et al., 2026
; 
Xue et al., 2026
; 
Xie et al., 2026
)
 has risen in recent years. In this section, we demonstrate that scaling laws can also be exploited in LLM-based recommendation models to predict the effectiveness of a new feature.

We consider a text-based recommendation setup where an LLM (or agent) receives information related to historical interaction events of a user with past items. The LLM is then prompted to recommend a single item from a large pool of candidate items. We probe the probability logit output of the LLM to compute the top 
 recommended items, which allows us to compute popular evaluation metrics such as HR@K.

We perform full-parameter finetuning on pretrained LLMs. Before finetuning, we preprocess the MovieLens-20M dataset so that in each data point, the LLM is given a historical context of the movies that the user has previously watched and rated. A list of 100 candidate movies with the correct next-watched movie inserted randomly is given to the LLM and the LLM is prompted to produce the next movie watched. Fig. 
8
 shows an example of one such preprocessed data point. The numerical score of each recommended movie corresponds to the probability logits produced by the finetuned LLM. Similar to the HSTU case, we treat the last movie watched by all users as a held-out validation set. Because our candidate set in the prompt is a list of 100 movies, we expect the HR@10 for this setup to be higher than that of HSTU (which considers all movies as candidates).

Interesting case studies

In this section, we present some interesting case studies we found in our experiments. The first case study highlights the prevalence of “crossover” effects during the training of recommendation models. The second case study presents some edge examples that we encountered in which scaling laws fail.

When applying new features to baseline recommendation models, we often observe “crossover points” in scaling curves. This is shown in the top row of Fig.

We occasionally observe that the scaling law in some settings does not follow a power-law fit. One extreme example is shown in Fig.

However, we do not expect them to appear often.

11. 
Conclusion

In this paper, we presented a method that exploits the feature-invariant scaling behavior of recommendation models to more efficiently determine the effectiveness of new feature changes. We show that different recommendation model families enjoy feature-invariant scaling laws. Then, we show that our method accurately predicts (with confidence intervals) the effectiveness of new feature changes on recommendation models, revealing numerous feature changes that improve HSTU’s SOTA performance on MovieLens-20M. Our method can be used as an efficient way for practitioners to evaluate large volumes of new recommendation algorithms and features at industry-scale.
