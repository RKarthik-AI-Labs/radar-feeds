Abstract.

Recent work in machine learning has demonstrated that transformer-based language model agents can communicate state not only through text, but also directly in latent space via key-value (KV) caches. In this paper, we argue that such cache-to-cache translation can provide utility beyond the original motivating application of real-time agent communication and can instead be utilized for retrieval-augmented generation (RAG). Building on the Cache-to-Cache (C2C) fusion framework, our proposed system CacheGraft encodes each corpus passage offline into a fused KV cache representation between a larger sharer model (4B parameters in our experiments) and a smaller receiver model (0.6B parameters) such that this cache can be injected into the receiver at query time with no need for the larger model. Across five QA benchmarks and two independent locally-run judges, CacheGraft improves answer quality over the text-only receiver baseline in 29 out of 30 comparisons, of which 17 of the 30 are statistically significant. Notably, these gains are zero-shot with respect to the fuser, which was never trained on retrieval data. These initial results suggest that latent-space document enrichment may be a promising avenue for enhancing the performance of RAG systems, particularly in compute-constrained settings where it is only feasible to deploy a small model at inference time.

retrieval-augmented generation, KV caching, model collaboration, cache translation

Recent breakthroughs in the machine learning community 
(
Fu et al., 2026
; 
Dery et al., 2026
; 
Rossi et al., 2026
)
 have demonstrated that transformer-based large language model (LLM) agents can communicate information between one another not only through the standard medium of text, but also in 
latent space
 by translating the key-value (KV) cache from a 
sender
 model to a 
receiver
 model’s internal vector space. Notably, this translation, typically accomplished by learning a separate adapter model, is feasible even if the two models have a differing number of weights and layers 
(
Fu et al., 2026
; 
Dery et al., 2026
; 
Rossi et al., 2026
)
.

The overarching motivation driving this effort in KV cache translation is the vision of heterogeneous LLMs collaborating in a real-time multi-agent system by passing state via KV cache vectors as opposed to raw text. By operating in latent space, KV cache translation offers the promise of improving both the 
quality
 of multi-agent computation, since KV caches constitute richer conceptual representations of information in an LLM’s native language, and the 
performance
 of such systems by eliminating the model’s initial step of converting a textual input into KV vectors.

The central observation behind this paper is that KV cache translation can be useful beyond the original motivating goal of real-time multi-agent LLM communication. To that end, we introduce the CacheGraft framework applying the KV cache translation paradigm for retrieval-augmented generation (RAG) where an LLM marshals knowledge from an external corpus to enhance its context before generating a response. Applying KV cache translation to RAG is not immediately obvious because typical RAG deployments often consist of a single LLM; it is unclear where cross-model cache translation even comes into the picture. Our key insight is that we can leverage KV cache translation during the 
offline indexing
 phase of RAG pipelines by enriching the representation of a document through fusing the KV cache of a larger model (that cannot be deployed at query time) with the cache of a smaller model that does run online. Thus, the larger model serves as a de facto teacher and guides the smaller receiver model to better “read" the contents of the documents.

Unlike multi-agent communication, the offline phase of a RAG pipeline is not latency-critical, making the overhead of KV cache fusion more palatable than in the real-time communication setting. Moreover, this offline phase may enable using more powerful, but computationally expensive LLM models for indexing. These insights drive the development of our CacheGraft framework. In summary, we make the following contributions in this paper:

•

 To our knowledge, this work is the first to make the observation that KV cache translation can be leveraged in applications outside of the canonical motivating example of real-time agent-to-agent communication. In particular, we demonstrate that the Cache-to-Cache (C2C) fusion technique 
(
Fu et al., 2026
)
 can lead to improved generation quality in retrieval-augmented generation (RAG) settings.

•

2. 
Related Work

Our work in this paper sits at the confluence of three research threads in machine learning and information retrieval that were previously disconnected. First is the aforementioned line of work on KV cache translation 
(
Fu et al., 2026
; 
Dery et al., 2026
; 
Rossi et al., 2026
)
 including the C2C framework 
(
Fu et al., 2026
)
 we directly use in our experiments. We focus on using C2C in our evaluation of CacheGraft because, to our knowledge, it has demonstrated efficacy with the largest gap between the sharer and receiver models (4B to 0.6B parameters) and thus constitutes the most scalable translation method to date.

Secondly, on the RAG front, a number of works have proposed precomputing and storing a model’s KV cache representation of documents and using the cache, not the raw text, at query time to reduce latency by eliminating the step of converting text into KV values 
(
Lu et al., 2025
; 
Chen et al., 2026
; 
Yao et al., 2025
; 
Ma et al., 2025
)
. However, these methods all use the KV cache of a single model and do not consider enriching the cache representation with signal from an additional, more powerful LLM, which differentiates our approach in this paper.

Finally, multiple research efforts have also examined the problem of 
document enrichment
, namely preprocessing the text in a corpus to be more amenable to RAG applications 
(
Chen et al., 2025
; 
O’Nuallain et al., 2026
; 
Uzan et al., 2026
; 
Lei et al., 2026
)
. CacheGraft can also be viewed as a document enrichment strategy, but in latent space as opposed to at the textual level.

4. 
CacheGraft: Adapting C2C for RAG

We now describe the details of our CacheGraft system. As a matter of notation, we will denote a RAG prompt by 
 which is a concatenation of a fixed preamble 
 (also known as a system prompt), a retrieved document 
, and the question 
. We focus our attention on knowledge-intensive question-answering applications that require a factual answer typically not found in the model’s own weights.

With causal attention, both models’ pre-fusion cache entries at
positions 
 are independent of any token at position 
; the projector acts
position-wise and layer-wise on those entries; and the fusion of

on 
. Hence computing

 alone yield identical KV over

position range, so no RoPE re-rotation 
(

(

Figure 
1
 depicts the full CacheGraft pipeline. Offline, for each passage, we prefill 
 with fusion enabled and
persist the receiver-space KV, keyed by a content hash. We also maintain an additional vector database index of document embeddings. Online, we identify the most relevant document to the query based on embedding similarity and load that document’s fused KV cache into the

base

5. 
Experiments

5.1. 
Experimental Setup

We conduct all experiments on a single NVIDIA A100-40GB GPU and use standard greedy decoding at inference time.

Models.

In all reported experiments, we use Qwen3-0.6B 
(
Yang et al., 2025
)
 as our receiver and Qwen3-4B-Base 
(
Yang et al., 2025
)
 as the sharer, with the released C2C projector for that pair. The projector is trained on general chat distillation and never sees
retrieval data, so every result is zero-shot with respect to fuser training.

Data.

We utilize five standard knowledge-intensive question answering benchmarks for our RAG evaluation: SQuAD v1.1 
(
Rajpurkar et al., 2016
)
, AdversarialQA 
(
Bartolo et al., 2020
)
,
CovidQA 
(
Möller et al., 2020
)
, QASPER 
(
Dasigi et al., 2021
)
 and
TriviaQA 
(
Joshi et al., 2017
)
. For search, we use bge-small 
(
Xiao et al., 2023
)
 embeddings to perform dense top-1 retrieval. For evaluation, we retain one question per gold passage. We also run our experiments under 
retrieved
 and 
oracle
 (perfect-retrieval) conditions to understand the impact of search quality on the overall RAG performance.

Metrics.

We utilize the LLM-as-judge mechanism 
(
Zheng et al., 2023
)
 as our primary evaluation metric. We evaluate all RAG outputs using two judges, both locally-run open-weight models scored on raw
unmodified generations: 
phi-4
 
(
Abdin et al., 2024
)
 and

Gemma-2-9B
 
(
Team et al., 2024
)
. We also report 
contains
 which measures whether the generated answer contains the gold ground truth answer included in the test dataset. We also compute statistical significance measures using the exact two-sided paired McNemar test over the set of evaluation questions. We do not rely on traditional RAG metrics such as Exact Match (EM) and F1 score because we observed that the generated answers from fused KV caches tend to be more verbose (illustrated in Table 
2
) which hurts performance on these token-centric metrics.

6. 
Limitations and Open Problems

6.1. 
Limitations

The primary practical limitation of our proposal is storage since we must store the KV cache for every document which can consume orders of magnitude more space than raw text (on the order of a terabyte for 100K documents, absent any optimizations). This problem is inherited from prior works that propose to precompute the KV caches for retrieval such as TurboRAG 
(
Lu et al., 2025
)
, Block Attention 
(
Ma et al., 2025
)
, and CAG 
(
Chan et al., 2025
)
 and can be mitigated with KV cache compression techniques 
(
Shi et al., 2024
)
 that are complementary to our work. Another limitation of our present study is that we focus on retrieving a single document and only consider a single C2C fuser model in our evaluations. Extending our system to support top-
 retrieval and additional models is another promising direction for future work.

6.2. 
Open Problems

The results in this paper present a proof of concept demonstration of KV cache fusion to enhance RAG applications and open many directions for future research in this domain. Below, we highlight two particularly interesting directions:

(1)

Training custom fuser models tailored for RAG:
 As mentioned previously, we consider a single off-the-shelf C2C fuser model that was not targeted for retrieval tasks. Could we improve the performance of CacheGraft by training a fuser model with retrieval-specific training objectives and datasets? How far can we scale the gap between the sharer and receiver model before cache fusion fails? Could we even train the fuser to be more compressible to augment standard KV cache compression techniques?

(2)

Combining with textual document enrichment:
 Prior work such as EnrichIndex 
(
Chen et al., 2025
)
 and AutoIndex 
(
O’Nuallain et al., 2026
)
 propose to modify document text to improve RAG performance. How does text-level document enrichment interplay with the latent space strategy of our method? Is there a text enrichment method that enhances KV cache translation beyond simply using the raw documents?

7. 
Conclusion

Thus far, the idea of translating the KV cache from one LLM to another possibly very different model has been applied exclusively to communicating state in real-time multi-agent systems. The key insight at the heart of this paper is that the same idea can be repurposed for RAG by applying KV cache translation on documents offline between a larger sharer model and a smaller receiver to enhance the receiver’s online answer quality. In fact, we argue that RAG might be an even 
better
 fit for the Cache-to-Cache fusion paradigm because running forward passes through both the sharer and receiver model (as C2C requires) is a negligible cost for offline document indexing, but may be limiting in real-time inference settings. We operationalize this insight in the form of CacheGraft, a prototype RAG system that utilizes C2C fusion to enrich a small receiver model’s KV cache representation with signal from a larger model that does not run at query time. Our initial evaluation extends C2C to zero-shot knowledge-intensive question answering tasks not present in fuser training where we find that CacheGraft consistently improves generation quality over the receiver-only text baseline on datasets where the larger sharer model has headroom to transfer. Perhaps surprisingly, these positive results on question-answering come from using an off-the-shelf pre-trained C2C fuser model that was not tuned for retrieval in any respect. Our findings also raise a number of interesting questions for future work, which we outline in Section 
6.2
, that we hope will drive further work on latent-space document enrichment for RAG applications.
